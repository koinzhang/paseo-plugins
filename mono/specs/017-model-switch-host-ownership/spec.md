# 017 · Provider 模型开关的主机归属

## 问题

Cursor 模型更新后，点击一项时其他开关也翻转。实际本机 Cursor 配置已有大量隐藏项，弹窗却全部显示开启。多个已连接主机各自运行 Mono client bundle，在同一弹窗复用开关；后扫描的实例覆盖 `aria-checked`，而点击回调仍属于最先创建按钮的实例，显示与持久化错配。

## 目标与验收

- Provider 弹窗仅由当前 Settings 路由所属主机的 Mono 控制；主机无法确认时不注入。
- 从旧实例接管按钮时替换其点击绑定，保存只写入当前主机。
- 旧版其他主机仍运行时，其状态覆盖也不能让当前开关翻转。
- 模型新增、删除、重排后按 provider + modelId 保持独立状态。
- 旧配置保持不变；typecheck、单元测试、Chromium 回归通过，reload 后 Mono running。

## 非目标

修改 Paseo 宿主、跨主机同步设置、发布 npm。模型选择数量的既有覆盖机制保持不变。
