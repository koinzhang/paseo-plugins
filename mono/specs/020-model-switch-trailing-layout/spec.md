# 020 · 模型开关固定行尾

## 目标

Settings → Providers 的模型列表中，Mono 可见性开关固定在每行右侧并垂直居中。长模型名称、ID 或说明不能把开关挤出视图。

## 行为

- Discovered 与 Custom 模型的开关保持同一右侧边距。
- 行内为开关及间距预留空间；名称、ID 和说明在剩余空间内单行省略。
- Custom 模型的删除按钮保留尺寸和点击区域，位于开关左侧。
- 保留开关状态、键盘聚焦、点击与主机隔离逻辑；卸载适配器后恢复宿主布局。

## 验收

- 长名称、长 ID、说明和自定义删除按钮在不同列表宽度下均不覆盖开关。
- 开关完整可见、各行右侧对齐，点击仍作用于对应模型。
- typecheck、单元测试与现有浏览器回归通过；重载 Mono 后 running，并检查实际 Provider 弹窗。
