# 048 — 热力图跨天保持完整矩形

## 目标

Global Activity 显示截至本地今天的最近 364 天，固定 52 列 × 7 行。
日期按列从上到下连续排列，今天始终位于右下角；跨天滚动一天，
不因自然周换周产生只显示一天的残缺末列，也不展示未来日期。
Today / 7D / 30D / All 保持相同布局，月份标签仍为 12 个。
Daily / Cumulative 口径不变；Weekly 仍按周日开始的自然周统计，
视觉列改为连续 7 天，不再代表自然周。

## 验收

- 覆盖周六到周日、跨月、跨年、闰日及夏令时边界，始终有 364 个可见日期。
- 三种模式均以今天结束，无未来或 excluded 格子。
- 自然周汇总与累计历史正确；typecheck 与现有测试通过。
