# 008 — 静默历史补扫

移除全局 Rescan history 及升级说明、agent panel 重扫按钮、Command Center 重扫入口和公开重扫 RPC 注册。保留内部幂等回填函数。

首次统计请求或 agent 生命周期事件取得 SDK 后，异步启动检查，不阻塞查询、不弹通知。取得 SDK 后每五分钟静默检查；并发请求合并。按 agent 最近活动和回填版本持久化成功检查点；升级首次补全历史消息，已完成且无变化的 agent 跳过。有变化的 agent 回扫 canonical 历史，保留现有幂等口径。失败不写成功标记，下次检查重试。

卸载停止定时器并取消后续翻页/写入。打开的统计页每十五秒刷新已入库结果；加载过数据后刷新不隐藏页面。

SDK 0.8 不提供入口级 paseo，后台首次启动依赖查询/生命周期提供的 context；只回填 agents.list 可枚举的会话（沿用现有范围）。
