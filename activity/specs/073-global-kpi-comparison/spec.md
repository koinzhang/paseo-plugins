# 073 — Global KPI 近 7 天对比

## 目标

- Global 的四个 KPI 格子显示上一段 7 天对比；Workspace / Agent KPI 不变。
- 当前窗口为含今天的最近 7 个本地自然日，基准为紧邻此前的 7 个完整自然日。两个窗口不重叠，Provider 筛选同时作用于对比。
- Sessions / Prompts 比较两个窗口的计数，显示 `↑20% vs prev. 7d`。Top provider / Top model 显示上一段 7 天各自排名第一的名称，英文示例 `Claude prev. 7d`；无记录时显示 `— prev. 7d`。
- 计数增长、下降、持平分别显示 `↑`、`↓`、`→`；基准为零而当前非零时显示 `—`，避免无定义的百分比。加载失败时不显示对比，不影响主 KPI。
- 文案随 Activity 已支持的语言设置切换。宽屏、窄屏的对比都位于 label 下方，使用与 label 相同的字号角色，不与数值或标签重叠。

## 验收

- 四格 KPI 均在 label 下方显示对比，筛选 Provider 后正确刷新。
- 对比数值符合本地数据库相邻 7 日窗口；跨月和夏令时不重复或漏算边界。
- 桌面 / compact 布局和明暗主题均能辨认。
