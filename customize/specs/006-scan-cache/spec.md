# Provider 扫描缓存与静默刷新

Customize 再次打开页面或切回已扫描的 Provider/Project 时，应立即显示上次的配置列表，同时后台重新扫描磁盘，更新列表而不打断浏览。

## 验收

- 扫描结果按 Provider 与 Project 分开缓存；页面离开后仍保留在当前插件运行时内，切回已扫描组合时不显示全页加载态。
- 每次进入页面或切换到已扫描组合时发起后台刷新；正在刷新时继续显示缓存列表。
- 后台刷新失败时保留缓存列表，用户可手动重试；首次扫描无缓存时维持现有加载和错误状态。
- Provider 快照与项目列表在再次进入页面时也优先显示缓存，以免挡住扫描结果。
- 插件运行时重新加载或应用重启后，内存缓存自然清空；不持久化包含本机路径和配置摘要的扫描结果。
