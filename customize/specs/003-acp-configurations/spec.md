# ACP Provider 配置发现

Customize 支持 Paseo ACP 清单中的 Cline、CodeBuddy Code、Gemini CLI、Goose、Grok Build、Kilo Code、Kiro CLI、Kimi Code、Qwen Code、TraeCode CLI，并补全 Cursor 的 commands、subagents、plugins。Provider 菜单继续只展示 Paseo 已启用的受支持 Provider。

## 验收

- 对每家列出已核实的 instructions、rules、skills、MCP、commands、subagents、plugins 机制与配置位置。
- 对确认的本地文件进行只读扫描；目录和配置文件可预览，MCP 密钥仍脱敏。
- 未经文档证实的能力显示“未验证”，不推断为不支持；运行时无法从磁盘确认的启用状态须说明。
- Provider ID 与 Paseo ACP catalog 一致；新分类有中英文标签。
