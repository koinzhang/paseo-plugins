# 025 — 卡片视图

## 目标

- 条目列表新增**卡片视图**：同一 scope / source 下的条目以响应式网格排列，卡片展示与列表行相同的信息（分类图标、名称、状态胶囊、描述、目录 / 原因 meta、token 与 Agent Plugins 胶囊）。
- 搜索框右侧新增视图切换图标按钮：列表视图显示网格图标（点击切到卡片视图），卡片视图显示列表图标（点击切回列表视图）；tooltip 与无障碍标签说明目标视图。
- 视图选择持久化在 Paseo host（与 Provider / Project 同一份 `board-selection` 设置），默认列表视图，插件重载 / app 重启后保留。
- 网格按可用宽度自适应：窄面板单列，宽面板最多 3 列；同一行卡片等高，选中态高亮，点击打开与列表相同的底部预览。

## 非目标

- 不改扫描、预览、搜索、Skills 筛选与计数逻辑。
- 不做卡片内联编辑、拖拽排序或自定义字段。
- 「暂无扫描位置」的分类不显示切换按钮（该分类没有搜索框，也没有条目）。

## 验收

- 列表视图下搜索框右侧出现网格图标按钮；点击后条目切换为卡片网格，按钮变为列表图标；再次点击恢复列表。
- 卡片视图与列表视图显示同样的条目集合与顺序（Project 在 User 前，source 内保持发现顺序），Project / User 节标题与 source 路径标签保留。
- 卡片包含名称、状态胶囊、描述（最多 2 行）、meta（目录 / 原因 / 标签，最多 2 行）、token 胶囊与 Agent Plugins 标记；`disabled` / `inactive` 条目同样置灰。
- 可用宽度 ≥ 744px 时 3 列，≥ 492px 时 2 列，更窄时 1 列（`GRID.minCardWidth` 240 + gap 12 推导）。
- 点击卡片选中并打开底部预览；再次点击取消；切换 Provider / Project / 分类 / 搜索 / Skills 筛选后的行为与列表一致。
- 视图选择在插件重载后保留；旧设置文档（无 `layout` 字段）解析为 `list`。
- `npm run typecheck`、`npm test` 通过；`paseo plugin reload customize` 后 running。
