# 方案

1. 服务端新增只读快照 RPC。按 Provider/Project 的哈希键读取 `$PASEO_HOME/plugin-data/customize/` 下的版本化 JSON，校验 schema、host home、请求键和扫描时间。缺失或无效时返回空；文件写入使用私有目录、私有文件和原子替换。
2. 原扫描 RPC 保持实时读取文件；成功后尽力写入快照，持久化失败不妨碍当前结果展示。扫描器规则变化时提升快照版本。
3. 客户端先请求快照；只有无快照或快照已过期时才启动扫描查询。运行时 React Query 缓存继续支持切换时立即显示结果；手动刷新直接执行实时扫描。
4. 从快照读取的路径仅作为列表候选；预览/打开时若路径尚未经本次运行时实时扫描授权，则针对原 Provider/Project 重新扫描确认。
