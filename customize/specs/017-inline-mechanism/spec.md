# 017 — 内联加载机制入口

## 目标

- 将 “How it loads” / “加载机制” 从独占一行的说明卡改为顶部工具栏入口。
- Skills 分类中顺序为调用方式筛选、加载机制、搜索框；其他支持扫描的分类为加载机制、搜索框。
- 点击入口后，在按钮下方显示与 Provider / Project 下拉菜单同风格的浮层，包含首条说明、扫描位置和其他说明；浮层不挤占工具栏行高。
- 不支持扫描的分类仍可查看机制说明。

## 验收

- 宽屏 Skills 分类中，加载机制入口位于筛选和搜索之间，顶部不再有独立说明行。
- 展开机制说明后能看到原有信息，点击按钮或浮层外可关闭，列表布局不变。
