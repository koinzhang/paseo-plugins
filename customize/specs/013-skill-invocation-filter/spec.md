# 013 — Skills 调用方式筛选

在 Skills 分类里，搜索栏旁提供三态开关，按调用方式收窄列表。

## 目标

- 仅在当前分类是 Skills 时显示开关，选项为全部、自动、仅手动。
- **自动**包含 `auto` 与 `conditional`（模型可直接选用，或在路径、globs、嵌套目录等条件满足时选用）。
- **仅手动**只包含 `status === "manual"`。
- **全部**不过滤，因此 `disabled`、`inactive`、`pending` 只出现在全部里。
- 开关上的数字是该档 skill 总数，不受搜索词影响。分类 Tab 上的 Skills 总数保持全量。
- Project / User 小节标题使用过滤后的数量。某一侧在当前筛选下没有条目时，显示「没有匹配项」。
- 默认全部。选择留在当前页面状态里，切换分类后隐藏控件、切回 Skills 时恢复；不写入 host settings。
- 当前预览的 skill 被筛掉时关闭预览。

## 非目标

- 不改扫描、RPC 或 `status` 的计算。
- 其他分类不提供这个开关。

## 验收

- Skills 下列出自动、按条件、仅手动、已禁用时：自动只留下前两类，仅手动只留下第三类，全部仍显示已禁用。
- 搜索与开关同时生效。
- 切到 Instructions 等分类时开关消失，列表不受上次选择影响。
- OpenCode 的 skill 均为自动时，仅手动计数为 0，列表为空并显示没有匹配项。
