# 021 — Provider 下拉分组与排序

## 目标

- Provider 下拉选项按来源分组：Built-in（内置）在上，ACP 在下。
- 每组内默认按显示名称排序（大小写不敏感升序）。
- 两组之间显示一条分割线，分割线上下留出间距，不与相邻选项贴在一起。
- 保持既有行为不变：只列已启用且受支持的 Provider、badge 显示来源、保存项失效时回退到首个可选项、Project 下拉不受影响。

## 非目标

- 不修改 Provider 快照读取、badge 文案、选择回退与扫描逻辑。
- 不给 Project 或其他下拉添加分组；只有一组时不显示分割线。

## 验收

- 同时存在 Built-in 与 ACP 选项时，下拉里 Built-in 全部在上、ACP 全部在下，组间有一条水平分割线，线与相邻选项之间留有间距。
- 每组内按名称排序；同名不同大小写按基础字符比较。
- 只有一组选项时不渲染分割线。
- `npm run typecheck`、`npm test` 通过，插件 reload 后 running。
