# Agent Plugins 规范版本

Customize 从插件根 `plugin.json` 的 `$schema` 读取 Agent Plugins 规范版本，并在标识中显示实际声明的完整版本号。

## 验收

- 当前支持的 `1.0.0` 清单通过对应规则校验后显示 `Agent Plugins 1.0.0`。
- 将来出现规范域名下的新版本清单时，显示声明版本并明确标为「未校验」；不套用 1.0.0 规则，也不称其符合新规范。
- 非规范 URL、专有清单或当前版本下无效的清单不显示标准标识。
- Provider 扫描不因新版本尚未支持而遗漏该根清单；现有 demo 继续显示正确版本。
