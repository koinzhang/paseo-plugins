# 028 — 图标一致性

## 目标

- 视图切换按钮（搜索框右侧的网格 / 列表图标）不再显示自定义 hover tooltip，仅保留无障碍标签。
- 配置条目（列表行与卡片）的类别图标从 `ICON_SIZE.leading`（18）改为 `ICON_SIZE.inline`（14），与工具栏图标、条目内文字对齐。

## 非目标

- 不改切换行为、持久化与无障碍标签。
- 不改状态 / token / Agent Plugins 胶囊与描述、meta 文本。

## 验收

- 切换按钮 hover 时不再出现浮层 tooltip；点击切换仍正常，读屏仍能读出「切换为卡片视图 / 列表视图」。
- 列表行与卡片的类别图标字形与工具栏图标同高（14px），并与首行标题垂直居中。
- `npm run typecheck`、`npm test` 通过。
