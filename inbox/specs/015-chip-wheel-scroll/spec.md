# 015 筛选 chip 行支持鼠标滚轮横向滚动

## 问题

全局页面的 project / workspace chip 行是单行横向 `ScrollView`，滚动条隐藏。web 上鼠标滚轮只产生纵向位移，超出宽度的 chip 被遮挡、无法点到；只有触控板横向轻扫能滚动。

## 已定决策

1. 两行仍保持单行横向滚动，不改为换行（标签多时换行会把列表挤下去）。
2. web 上在 chip 行内滚动鼠标滚轮时，纵向位移转为横向滚动；已滚到头时不拦截，外层继续纵向滚动。横向位移（触控板、Shift+滚轮）保持浏览器默认行为。
3. 原生端不变（手指横向拖动本来可用）。

## 验收

- [ ] project / workspace chip 超出宽度时，鼠标滚轮可以把后面的 chip 滚出来并点击。
- [ ] 滚到最左 / 最右后继续滚轮，页面不被卡住。
- [ ] 触控板横向轻扫行为不变。
