# 003 Inbox 排序

## 目标

全局 Inbox 页面「+ Note」右侧增加排序按钮，可按 **收藏时间 / 创建时间 / 修改时间 / 名称** 排序。

## 已定决策

1. 选项与含义：
   - **Starred（收藏时间）**：条目加入 Inbox 的时间（`items.created_at`）。
   - **Created（创建时间）**：agent 取 agent 自身的创建时间（收藏时写入快照 `agentSnapshot.createdAt`；旧条目无此字段时退回加入 Inbox 的时间）；note / scratch 即条目创建时间。
   - **Updated（修改时间）**：`items.updated_at`，默认值，与 001 的行为一致。
   - **Name（名称）**：与列表标题一致（agent 标题 / note 标题 / 正文首行），不区分大小写、数字按数值比较，A→Z。
2. 时间类排序一律新→旧；名称 A→Z；不提供升降序切换。
3. 置顶条目始终在最前，排序只作用于置顶组内和非置顶组内。
4. **单按钮循环切换**：按钮显示当前排序名，每点一次切到下一种（Updated → Starred → Created → Name → Updated），不展开选项列表。（006 起按钮改为只显示当前排序的图标。）
5. 按钮只出现在全局页面；Explorer 的 workspace Inbox 面板保持默认的修改时间排序。007 起全局页面的排序写入 host settings，重开后恢复。

## 验收

- [ ] 全局页面「+ Note」右侧出现排序按钮，显示当前排序名；每次点击切到下一种排序并重新排序。
- [ ] 列表栏宽度不足时搜索框收缩，按钮不越过列表与详情的分割线。
- [ ] 分割线可左右拖动调整列表 / 详情宽度（280–640，默认 360），app 运行期间重开页面保持拖动后的宽度。
- [ ] 四种排序结果符合上述定义，置顶条目始终在前。
- [ ] 新收藏的 agent 按 Created 排序时使用 agent 自身创建时间。
