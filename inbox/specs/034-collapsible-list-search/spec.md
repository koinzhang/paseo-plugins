# 034 列表工具栏轻量图标与展开搜索

## 目标

- 全局 Inbox 与 Workspace Inbox 的列表工具栏参考 Activity Workspace Agents 标题行：默认不展示常驻搜索框，只在右侧展示轻量搜索图标。
- 点击搜索图标后，在筛选按钮左侧展开胶囊输入框；展开时搜索图标变为关闭图标，右侧其他操作保持原位。
- 移除列表工具栏搜索、筛选、新建笔记、收藏 agent、排序图标的边框，不改变详情页和列表行操作样式。

## 决策

1. 搜索框展开 / 收起使用宽度和透明度动画；展开完成后自动聚焦，支持输入并沿用现有列表查询。
2. 收起搜索后清空关键词；搜索词和展开状态仍只保留在当前会话，不写入设置。
3. 工具栏图标使用透明背景，仅在按压或展开时显示轻量反馈；搜索输入框自身保留边框。
4. 筛选菜单、新建笔记、收藏 agent、排序及候选列表的既有行为不变。
5. 图标槽与 Activity Agents 一致：宽 / 高 `24px`、相邻按钮 `gap: 2`、操作区 `marginLeft: 2`；筛选按钮只显示 `16px` ListFilter 图标，移除右侧 ChevronDown，避免双图标显得过小、过密。
