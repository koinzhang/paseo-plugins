# 036 Detail content alignment

## 目标

- Workspace 与全局详情页的标题文字、Project / Workspace 标签、编辑标题和正文使用同一左起点。
- 保留 compact 详情的返回操作、条目标识图标和现有操作顺序。

## 决策

1. compact 详情的返回按钮与文档 / agent 图标组成独立的轻量导航行，不再和标题文字同行。
2. 详情标题单独占一行，放在详情内容容器左边缘，与下方标签及编辑器对齐。
3. 非 compact 详情保留条目标识图标和标题同行；图标之后的标题仍单行缩略，agent 权限徽标位置不变。
4. 标签、编辑器和操作按钮的现有布局及交互不变。

## 验收

- compact 详情标题文字与标签、编辑标题和正文左对齐；返回按钮保留并可操作。
- 非 compact 详情原有图标与标题布局不变。
- typecheck、完整测试、diff check 和插件 reload 通过；实际界面读取 compact 标题、标签、编辑标题和正文的坐标。
