# 037 Detail header alignment

## 背景

036 为让 compact 详情的标题与标签、编辑区左对齐，把返回 / 图标导航和标题拆成两行。实际界面里标题因此看起来像换到了下一行。用户明确要求保留标题回到导航行的回退，不恢复 036 的标题拆行。

## 目标

- compact 详情的返回箭头视觉左边缘对齐 Project / Workspace 标签和编辑区。
- 标题保持与返回按钮、条目标识同一行，并继续单行缩略。

## 决策

1. 保留 036 标题拆行的回退，compact 详情使用原来的单行导航 + 标题结构。
2. 返回按钮向左偏移 6px，抵消 `ChevronLeft` 图标在 20px 画布内的视觉留白，让箭头左边缘与标签、编辑区左边缘对齐。
3. 不改标签、编辑器和操作按钮的现有位置；非 compact 详情布局不变。

## 验收

- compact 详情中返回箭头、Project / Workspace 标签和编辑区左边缘对齐。
- 标题与返回按钮、条目标识同一行，长标题单行缩略。
- typecheck、完整测试和 diff check 通过；reload 后在实际界面确认箭头与内容左对齐。
