# 038 Inline detail title

## 背景

note 详情页头展示一次标题，正文编辑容器里又有单独的 Title 输入项，重复且占空间。标题仍用于列表、搜索与名称排序，不能删除数据字段。

## 目标

- note 详情页头的标题本身可直接编辑，不再在正文编辑区显示单独的 Title 输入项。
- 新笔记同样通过页头填写标题；未填写标题时继续沿用现有空标题占位与列表回退。

## 决策

1. note 的页头静态标题替换为无边框、单行的标题输入框，位置与返回按钮、文档图标同行；agent 页头仍为只读静态标题。
2. 标题输入与现有 `NoteEditor` 共用 `title` 状态和自动保存逻辑，不新增保存按钮或 RPC，不改变 600ms 防抖、离开时保存、空笔记清理及远端更新保护。
3. 删除正文编辑容器中的标题输入项及其下方分隔线，正文编辑区保持无边框并自动聚焦新笔记。
4. 保留标题为空时的现有语义：正文仍可独立保存，列表继续由正文首行或 Untitled note 回退。

## 验收

- 全局与 Workspace 的 note 详情只有一处标题编辑入口，即页头标题；agent 详情不可编辑标题。
- 在页头修改标题后复用原有自动保存，列表、搜索、排序及重新打开详情均使用新标题。
- 新建笔记、空标题、自动保存和离开详情行为不回归。
- typecheck、完整测试、diff check 与插件 reload 通过；检查实际详情的标题输入与正文编辑区。
